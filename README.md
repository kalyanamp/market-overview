# Market Overview

Two daily pages, both served via GitHub Pages:

- **[Pre-Market Wrap](index.html)** — index levels, Fed/macro read, SPX/QQQ
  options positioning (GEX), a stock watchlist, and the week's macro
  calendar. Each day's snapshot is also kept as
  `market-wrap-YYYY-MM-DD.html/.png/.pdf`.
- **[0DTE/1DTE Session Brief](0dte-brief.html)** — a naked calls/puts,
  intraday-only pre-market brief for SPX: bull/bear factor weights, an
  SPX/VIX outlook, a VIX regime ladder, key SPX levels, an event timeline,
  and a net directional bias with confidence. Each day's snapshot is also
  kept as `0dte-premarket-brief-YYYY-MM-DD.html`.

Not investment advice — for personal reference only.
